# College logos

Drop logo files here named after the college slug from
`../data/advanced-manufacturing-programs.json`, e.g.:

    albany-technical-college.png
    athens-technical-college.png
    atlanta-technical-college.png

Square-ish transparent PNGs around 200x200 render best. The card slot is
52x52 with `object-fit: contain`.

Missing files are fine: the `<img>` removes itself and the lettered
monogram shows instead.
